# 免费定时收益报表

这是待发布源码，还没有产生公网网址。无需运行本机服务；浏览器仅获取公开静态数据，不接触飞书密钥。

1. 在 GitHub 免费账号创建公开仓库，把本目录所有文件（包括 .github 目录）上传到仓库根目录。
2. Settings → Pages → Source 选择 GitHub Actions。
3. Settings → Secrets and variables → Actions 新建 LARK_APP_ID、LARK_APP_SECRET 两个仓库 Secret。不要上传到代码文件。
4. 飞书应用需支持应用身份，开通并发布表格读取和 Wiki 节点读取权限；将应用添加到目标知识库/表格允许访问的成员。此前本机用户授权不会自动赋予应用身份读取权限。若应用不支持机器人/应用身份，需要新建企业自建应用。
5. Actions → Sync Feishu and publish report → Run workflow。首次运行必须成功，再使用部署步骤输出的网址。

默认每小时第17分钟触发（UTC；对应北京时间也为每小时17分）。GitHub调度可能延迟或跳过；公开仓库长期无活动时可能暂停计划任务，需要人工重新启用。不保证精确准点或全年无故障。每次失败任务会变红，已发布的上次成功快照保持不变。页面展示最后成功同步时间，检查是否过期。

报表及精简后的日期、ID、收益数据将对所有访问者公开。不要提交任何认证配置、App Secret 或原始本机凭证。免费GitHub Pages通常需要公开仓库，具体限制以账号方案为准。部分网络对github.io的访问可能不稳定。

当前已检查脚本语法与模拟数据解析；实际应用权限和首次云端同步仍待验证。没有内置任何密钥或虚构报表数据。
